## 简介

基于多层感知机 (MLP) 的加密货币价格预测系统，采用五模型投票机制，交叉验证准确率达 92.94%。

## 核心特性

- 五模型投票: RF + GB + MLP + LR + SVM
- 高置信度评估: 过滤低质量信号
- 多币种支持: BTC/ETH/SOL/BNB/ADA
- 回测引擎: 24 个月模拟交易

## 模型表现

| 模型 | 准确率 |
|------|--------|
| Random Forest | 89.1% |
| Gradient Boosting | 90.3% |
| MLP (主模型) | 92.94% |
| Logistic Regression | 87.5% |
| SVM | 88.2% |
| **集成投票** | **92.94%** |
